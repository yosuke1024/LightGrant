# Security Policy

## Supported Versions

We actively support and patch the following versions of LightGrant:

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| < 0.1.0 | No        |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please **do not open a public GitHub issue**. Instead, report it privately to our security team to ensure a coordinated disclosure process.

### Contact Info
Please email your findings to **security@example.com**.

### Information to Include
To help us triage and resolve the issue quickly, please include:
- A detailed description of the vulnerability.
- Steps to reproduce or a proof-of-concept (PoC).
- The potential impact and how it can be exploited.
- Any suggested mitigations or patches.

### Response Commitments
- **Acknowledgment**: We will acknowledge receipt of your report within 48 hours.
- **Triage**: We will provide an initial assessment and status update within 7 days.
- **Remediation**: We aim to release a patch for verified vulnerabilities within 30 days.

Thank you for helping keep LightGrant secure!
